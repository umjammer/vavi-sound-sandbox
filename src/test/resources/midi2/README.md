# midi2

MIDI Clip Files (`SMF2CLIP`) taken from
[jazz-soft/test-midi-files](https://github.com/jazz-soft/test-midi-files/tree/main/midi2) (MIT License).

| file                              | what it is                                                        |
|-----------------------------------|-------------------------------------------------------------------|
| `test-empty.midi2`                | the 8 byte header and nothing else                                |
| `test-not-a-midi-file.midi2`      | not a clip at all, for the negative test                          |
| `test-minimal.midi2`              | Start of Clip and End of Clip only                                |
| `test-c-major-scale-m1-g0.midi2`  | a C major scale as MIDI 1.0 Channel Voice messages, group 0       |
| `test-c-major-scale-m2-g0.midi2`  | the same scale as MIDI 2.0 Channel Voice messages, group 0        |
| `test-gm2-doggy-78-00-38-4c.midi2`| metadata text, a GM2 System On SysEx and a bank select of 78:00:38 |
